# Assessment submission checklist

The app package covers the technical dashboard, cleaning pipeline, five research questions, nine visuals and documentation. The following account-specific and student evidence remains to be completed:

- Run locally using README.md and inspect every tab.
- Add your name and candidate number to your submission document.
- Include CRS Artificial Intelligence, Mathematics for AI-II and your school name.
- Add a short background research discussion with citations explaining why length of stay, severity and financial patterns matter to hospital operations.
- Upload the extracted project files to your GitHub repository.
- Deploy app.py to Streamlit Cloud; test the live URL.
- Add the actual live link and dashboard screenshots to README.md.
- Ensure assessor access as required by the brief for ai.assignments@wacpinternational.org; confirm the correct GitHub collaborator account if the repository is private.
- Create the final submission PDF with your student details, GitHub link and live link.

Do not report readmission rates, unique patient counts or monthly trends from this file. The required identifiers and dates are absent.
